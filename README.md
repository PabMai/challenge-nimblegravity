# Challenge Junior Fullstack Developer

  Challenge para el rol Junior Fullstack Developer.

  ## Tecnologías instaladas

  - React
  - TypeScript
  - Vite
  - ESLint (configuración básica)


## Instrucciones de inicio para desarrollo

Antes de iniciar el proyecto, copia el archivo `.env.example` y renómbralo a `.env` en la raíz del proyecto:

```bash
cp .env.example .env
```

Luego, instala las dependencias y ejecuta el servidor de desarrollo:

## Comandos (desarrollo)

  Ejecuta los siguientes comandos desde la raíz del proyecto:


  ```bash
  # Usando npm
  npm install      # Instalar dependencias
  npm run dev      # Inicia el servidor de desarrollo (Vite)
  npm run build    # Genera build de producción
  npm run preview  # Sirve la build en modo preview (Vite)
  ```

  ```bash
  # Usando yarn
  yarn install     # Instalar dependencias
  yarn dev         # Inicia el servidor de desarrollo (Vite)
  yarn build       # Genera build de producción
  yarn preview     # Sirve la build en modo preview (Vite)
  ```
